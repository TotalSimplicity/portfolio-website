## Inventory application

Wilton Public Schools tracked devices across three systems that didn't talk to each other. I built one interface for circulation staff that:

- Pulls 9,277 assets and their users from Snipe-IT
- Merges in student data from PowerSchool, including custom fields like device insurance
- Shows each device's last-logged-in IP from Google Admin and can disable devices there
- Is designed to automatically disable overdue and out-of-district devices

## Infrastructure

- Migrated the whole district's phones from Avaya to Yeastar, using DHCP options to handle firmware updates automatically
- Set up NDI networking for remote PTZ camera control and recording
- Helped add IPv6 to the district network
